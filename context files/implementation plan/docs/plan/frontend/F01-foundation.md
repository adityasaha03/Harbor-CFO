# F01 Next.js foundation

Depends: S00. Priority: P0. Read first: ARCHITECTURE.md sections 1, 4, 9.

## Goal

A clean Next.js App Router app with Tailwind, shadcn/ui primitives, providers, the app shell, and shared UI helpers that every feature reuses.

## Files (`apps/web`)

- Generated by `create-next-app` (TypeScript, App Router, Tailwind, ESLint, `src/` directory, alias `@/*`); rename package to `@harbor/web`; extend the root ESLint and tsconfig base
- `next.config.ts` (`transpilePackages: ['@harbor/contracts']`), `.env.example`, `vitest.config.ts`, `vitest.setup.ts`
- `src/lib/env.ts` (Zod-validated `NEXT_PUBLIC_*`), `src/lib/utils.ts` (`cn`)
- `src/components/ui/*` shadcn primitives: button, card, dialog, sheet, table, tabs, badge, input, label, select, textarea, skeleton, alert, tooltip, dropdown-menu, separator, sonner
- `src/components/layout/app-shell.tsx`, `sidebar-nav.tsx`, `page-header.tsx`, `synthetic-data-badge.tsx`
- `src/components/feedback/query-boundary.tsx` (loading, empty, error, data), `empty-state.tsx`, `error-state.tsx`
- `src/components/data/money.tsx` (`<Money minor={...} />` using `formatMinor` from contracts), `date-label.tsx`, `severity-badge.tsx`
- `src/providers/query-provider.tsx`, `theme-provider.tsx`, `src/app/layout.tsx`, `src/app/globals.css`
- `src/app/(app)/layout.tsx` placeholder (auth guard added in F03), placeholder pages for each route (`dashboard`, `imports`, `forecast`, `alerts`, `financing`, `scenarios`, `actions`, `agent`, `proof`, `settings`) each rendering a `PageHeader`

## Specification

- Design direction: calm, dense-but-readable finance UI; neutral palette with one accent colour; semantic colours only for severity (critical, high, medium, info) and good/warning status; consistent 4/8 px spacing; tabular numbers for money; light and dark themes; no emoji; plain, specific copy.
- Sidebar items: Dashboard, Imports, Forecast, Alerts, Financing, Scenarios, Actions, Agent, Proof, Settings. Items are data-driven (array with `href`, `label`, `icon`, `permission?`) so F04 can filter by permission.
- `SyntheticDataBadge` shows "Synthetic demo data" in the shell header on every screen.
- `QueryBoundary` takes a TanStack Query result and renders skeleton, `EmptyState`, `ErrorState` (with retry) or children; all feature screens use it.
- Every `page.tsx` under 40 lines.
